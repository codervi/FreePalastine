## 🇬🇧 English

This project is a web platform dedicated to preserving history, raising awareness, and building a solidarity community for a free Palestine.

### 🚀 Features
- **Historical Archive:** A visual, chronological timeline of historical events with detailed descriptions, images, and source links.
- **Community Forum:** A fully integrated discussion board featuring categories, threads, and user replies to foster community engagement.
- **Role-Based Management:** Secure authorization system granting 'SuperUser' and 'Chef' roles exclusive access to add, edit, or delete historical records.
- **Secure Authentication:** Robust user management with PBKDF2 password hashing and CSRF protection for secure form submissions.
- **Modern & Responsive UI:** Mobile-first design utilizing Bootstrap 5, interactive modals, and custom CSS.

### 🛠 Tech Stack
- **Framework:** ASP.NET Core 8.0 MVC
- **ORM:** Entity Framework Core
- **Database:** MS SQL Server
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Typography:** Google Fonts (Montserrat)

### 📂 Project Modules
- `History`: Archival display of events with secure CRUD operations for admins.
- `Forum`: Dynamic category and thread-based community discussion system.
- `Authentication`: Login, registration, and role management.

### 🍉✊ Justice for Palestine
"A fairer world begins with a free Palestine."

## 🇹🇷 Türkçe

Bu proje, tarihi korumaya, farkındalık yaratmaya ve özgür bir Filistin için dayanışma topluluğu oluşturmaya adanmış bir web platformudur.

### 🚀 Özellikler
- **Tarih Arşivi:** Tarihi olayların detaylı açıklamalar, görseller ve kaynak bağlantıları ile sunulduğu görsel ve kronolojik bir zaman çizelgesi.
- **Topluluk Forumu:** Topluluk etkileşimini güçlendirmek için kategoriler, konu başlıkları ve kullanıcı cevapları içeren tam entegre bir tartışma panosu.
- **Rol Bazlı Yönetim:** Tarihi kayıtları ekleme, düzenleme veya silme yetkisini sadece 'SuperUser' ve 'Chef' rollerine veren güvenli yetkilendirme sistemi.
- **Güvenli Kimlik Doğrulama:** Güvenli form gönderimleri için CSRF koruması ve PBKDF2 parola şifreleme ile sağlam kullanıcı yönetimi.
- **Modern ve Duyarlı Arayüz:** Bootstrap 5, etkileşimli modallar ve özel CSS kullanan, mobil uyumlu tasarım.

### 🛠 Teknoloji Yığını
- **Altyapı:** ASP.NET Core 8.0 MVC
- **ORM:** Entity Framework Core
- **Veritabanı:** MS SQL Server
- **Ön Yüz:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Tipografi:** Google Fonts (Montserrat)

### 📂 Proje Modülleri
- `History`: Yöneticiler için güvenli CRUD işlemleriyle olayların arşivsel gösterimi.
- `Forum`: Kategori ve konu odaklı dinamik topluluk tartışma sistemi.
- `Authentication`: Giriş, kayıt ve rol (yetki) yönetimi.

### 🍉✊ Filistin İçin Adalet

## 🇵🇸 العربية (Arabic)

هذا المشروع هو منصة ويب مخصصة للحفاظ على التاريخ، وزيادة الوعي، وبناء مجتمع تضامني من أجل فلسطين حرة.

### 🚀 الميزات
- **الأرشيف التاريخي:** تسلسل زمني مرئي للأحداث التاريخية مع أوصاف تفصيلية، صور، وروابط للمصادر.
- **منتدى المجتمع:** لوحة نقاش متكاملة تحتوي على فئات، مواضيع، وردود من المستخدمين لتعزيز التفاعل المجتمعي.
- **الإدارة القائمة على الأدوار:** نظام تفويض آمن يمنح صلاحيات حصرية لأدوار 'SuperUser' و 'Chef' لإضافة، تعديل، أو حذف السجلات التاريخية.
- **مصادقة آمنة:** إدارة قوية للمستخدمين مع تشفير كلمات المرور (PBKDF2) وحماية (CSRF) لضمان أمان النماذج.
- **واجهة حديثة ومتجاوبة:** تصميم متوافق مع الهواتف المحمولة باستخدام Bootstrap 5، نوافذ منبثقة تفاعلية، وCSS مخصص.

### 🛠 التقنيات المستخدمة
- **إطار العمل:** ASP.NET Core 8.0 MVC
- **إدارة قواعد البيانات (ORM):** Entity Framework Core
- **قاعدة البيانات:** MS SQL Server
- **واجهة المستخدم (Frontend):** HTML5, CSS3, JavaScript, Bootstrap 5
- **الخطوط:** Google Fonts (Montserrat)

### 📂 وحدات المشروع
- `التاريخ (History)`: عرض أرشيفي للأحداث مع عمليات آمنة للمسؤولين (إضافة، تعديل، حذف).
- `المنتدى (Forum)`: نظام نقاش مجتمعي ديناميكي يعتمد على الفئات والمواضيع.
- `المصادقة (Authentication)`: تسجيل الدخول، إنشاء حساب، وإدارة الصلاحيات.

### 🍉✊ العدالة لفلسطين
"عالم أكثر عدلاً يبدأ بفلسطين حرة."
