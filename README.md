# ForFreePalestine 🍉

This project is a web platform dedicated to raising awareness and creating a community for a free Palestine.

## 🚀 Features
- **Secure Authentication:** Password hashing with PBKDF2.
- **CSRF Protection:** Secure form submissions.
- **Modern UI:** Responsive design with Bootstrap and custom CSS.

## 🛠 Tech Stack
- ASP.NET Core 8.0 MVC
- Entity Framework Core
- MS SQL Server
- Google Fonts (Montserrat)

"A fairer world begins with a free Palestine."
